# 访问统计与收藏验收

日期：2026-10-26（北京时间）。关联 [Issue #61](https://github.com/tans/jack-cases/issues/61)。

使用独立临时 SQLite 数据库与虚构账号验收；图片中的浏览量为本地验收数据，不能作为生产流量。没有新增或修改测试代码。

## 已验证

- 全新数据库成功执行 10 条迁移；本地旧数据库的备份副本可升级；`foreign_key_check` 无异常。原数据库未修改。
- 同一页面事件重复提交返回成功但只计 1 次。两次不同页面访问（公开案例与作者需求详情）合计增加 2 PV。
- 修正 ORM 相关子查询的外层字段限定后，需求和对应案例的浏览量一致；不同需求与独立案例分别为 `3 / 3`、`1 / 1`、`1`，互不串计，后台需求列表显示相同数字。
- 北京时间日界线验证：插入昨日、6 天前和 7 天前三条临时记录后，累计为 18、今日为 15、近 7 天为 17，符合包含今日的 7 个自然日口径。
- 未登录上报私有需求返回 401，普通用户上报后台页面返回 403，非法页面路径返回 400；普通用户不能读取后台统计。
- 重复收藏仅保留一条，重复取消成功；不同账号收藏隔离。下架后收藏列表隐藏且不能重新收藏或读取详情，重新发布后原收藏恢复。
- 浏览器验证卡片收藏、详情已收藏状态、刷新持久化、我的收藏入口、取消后空态、后台统计及需求列表浏览量。页面路径不变的收藏/数据刷新不增加 PV；开发模式重复渲染不增加 PV。
- 桌面 1440px 和手机 390px 页面检查，统计与收藏页面均无水平溢出；后台宽表在表格容器内横向滚动。浏览器响应尺寸覆盖已恢复。
- `npm run typecheck`、`npm run build`、`git diff --check` 通过。构建保留现有主包大小提示。

## 现有测试边界

`npm test`：78 项中 59 项通过、19 项失败。在修改前的 `3ac3ffa` 归档副本中用相同依赖与环境复跑，结果仍为 59 / 19，失败名称完全一致，无新增失败。旧测试包含已删除的 `share_consent`、旧媒体字段和旧 API Key 权限规则等断言。本次未修改这些测试。

Impeccable 静态检查仅报告现有大组件中相邻颜色类的警告；本次新增统计、收藏与详情动作经过实际页面检查。它不是完整的无障碍审计。
